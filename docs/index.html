Load the folder of instruction audio. Pick the track, then arm backup. The first ~30 s from the first sound (leading silence is skipped) becomes a peak-hash fingerprint. The mic records short clips; only the current clip is shown on Heard. Matching clips count toward lock — talking and other room noise is ignored. Cutout only fires if the mic goes quiet where the file still has speech. The folder and fingerprints stay on this phone.
